# ADR-0005: EIP-712 订单签名与验证

## 状态

已采纳

## 背景

用户通过链下 RFQ 获取报价，生成 EIP-712 签名订单。协议服务器验证签名和价格后提交至 `MonogramMinting`。订单一旦被用户签名，协议无法修改其内容。

## 决策

### EIP-712 Domain

```solidity
bytes32 private constant EIP712_DOMAIN_TYPEHASH = keccak256(
    "EIP712Domain(string name,string version,uint256 chainId,address verifyingContract)"
);

bytes32 private constant EIP_712_NAME = keccak256("MonogramMinting");
bytes32 private constant EIP712_REVISION = keccak256("1");

_domainSeparator = keccak256(abi.encode(
    EIP712_DOMAIN_TYPEHASH,
    EIP_712_NAME,
    EIP712_REVISION,
    block.chainid,
    address(this)
));
```

### Order TypeHash

```solidity
bytes32 private constant ORDER_TYPEHASH = keccak256(
    "Order(uint8 order_type,uint256 expiry,uint256 nonce,address benefactor,"
    "address beneficiary,address collateral_asset,uint256 collateral_amount,"
    "uint256 m_amount)"
);

function hashOrder(Order calldata order) public view returns (bytes32) {
    return keccak256(abi.encode(
        ORDER_TYPEHASH,
        order.order_type,
        order.expiry,
        order.nonce,
        order.benefactor,
        order.beneficiary,
        order.collateral_asset,
        order.collateral_amount,
        order.m_amount
    ));
}

function _hashTypedData(bytes32 structHash) private view returns (bytes32) {
    return keccak256(abi.encodePacked("\x19\x01", _domainSeparator, structHash));
}
```

### 签名验证

```solidity
function _verifyOrder(Order calldata order, Signature calldata signature) private view {
    if (block.timestamp > order.expiry) revert SignatureExpired();

    bytes32 digest = _hashTypedData(hashOrder(order));

    if (signature.signature_type == 0) {
        // EIP-712
        address signer = ECDSA.recover(digest, signature.signature_bytes);
        if (signer != order.benefactor) revert InvalidSignature();
    } else if (signature.signature_type == 1) {
        // EIP-1271 — 支持合约钱包
        if (!_isValidEIP1271Signature(order.benefactor, digest, signature.signature_bytes))
            revert InvalidSignature();
    } else {
        revert InvalidSignatureType();
    }
}
```

### EIP-1271 支持（V2 特性）

```solidity
function _isValidEIP1271Signature(
    address signer, bytes32 digest, bytes calldata signature
) private view returns (bool) {
    (bool success, bytes memory result) = signer.staticcall(
        abi.encodeWithSelector(IERC1271.isValidSignature.selector, digest, signature)
    );
    return success && result.length == 32 && abi.decode(result, (bytes4)) == IERC1271.isValidSignature.selector;
}
```

### Nonce Bitmap 防重放

```solidity
mapping(address => mapping(uint256 => uint256)) private _orderBitmaps;

function _deduplicateOrder(address sender, uint256 nonce) private {
    uint256 bitmapSlot = nonce / 256;
    uint256 bit = 1 << (nonce % 256);

    uint256 bitmap = _orderBitmaps[sender][bitmapSlot];
    if (bitmap & bit != 0) revert InvalidNonce();

    _orderBitmaps[sender][bitmapSlot] = bitmap | bit;
}
```

### 链下验证流程

提交到链上前，协议服务器执行 11 项验证：

| # | 验证 | 位置 | 说明 |
|---|------|------|------|
| 1 | 签名有效 | 链上 | ECDSA.recover 验证 |
| 2 | 系统健康 | 链下 | 对冲系统正常运行 |
| 3 | 白名单 | 链上 | benefactor 地址已批准 |
| 4 | 受益人白名单 | 链上 | beneficiary 已获 benefactor 批准 |
| 5 | 余额充足 | 链下 | benefactor 持有足够资产 |
| 6 | 订单时效 | 链下 | 报价返回后及时提交 |
| 7 | expiry 合法 | 链上 | ≥30 秒后过期 |
| 8 | RFQ 匹配 | 链下 | 订单参数与报价一致 |
| 9 | Last-look 价格 | 链下 | 当前价格在容忍范围内 |
| 10 | 外部价格校验 | 链上 | Pyth + Chainlink ±5% |
| 11 | 每区块限额 | 链上 | 不超过 per-block 上限 |

### 受益人白名单

```solidity
// benefactor 可以为自己批准受益人地址
mapping(address => mapping(address => bool)) public approvedBeneficiary;

function setApprovedBeneficiary(address beneficiary, bool status) external {
    approvedBeneficiary[msg.sender][beneficiary] = status;
    emit BeneficiaryUpdated(msg.sender, beneficiary, status);
}

// 在 verifyOrder 中检查
function _checkBeneficiary(Order calldata order) private view {
    if (order.benefactor != order.beneficiary) {
        if (!approvedBeneficiary[order.benefactor][order.beneficiary])
            revert BeneficiaryNotApproved();
    }
}
```

## 后果

### 正面
- EIP-712 确保订单不可篡改
- EIP-1271 支持做市商合约钱包
- Nonce bitmap 高效防重放

### 负面
- 签名验证增加 Gas 成本
- EIP-1271 静态调用增加外部依赖风险

### 不采用的设计
- ❌ DelegatedSigner — 增加不必要的授权路径
