# ADR-0004: 角色权限与访问控制

## 状态

已采纳

## 背景

MonogramMinting 使用 OpenZeppelin AccessControl 定义 4 个角色。各角色严格分离权限，GATEKEEPER 只拥有紧急关停能力，不能授权或开启。ADMIN 多签操作需 7 天时间锁。

## 决策

### 角色定义

| 角色 | 标识符 | 权限 | 负责人 | 数量 |
|------|--------|------|--------|------|
| `DEFAULT_ADMIN_ROLE` | `keccak256("DEFAULT_ADMIN_ROLE")` | 全权限：管理角色、资产、custodian、参数、时间锁 | 7/10 多签 | 1 |
| `MINTER_ROLE` | `keccak256("MINTER_ROLE")` | 调用 `mint()`、`transferToCustody()` | 协议运营方 | ~20 EOA |
| `REDEEMER_ROLE` | `keccak256("REDEEMER_ROLE")` | 调用 `redeem()` | 协议运营方 | ~20 EOA |
| `GATEKEEPER_ROLE` | `keccak256("GATEKEEPER_ROLE")` | 关停 mint/redeem、移除角色 | 内签 3+ + 外部 3+ | 6+ EOA |

### 权限矩阵

| 操作 | ADMIN | MINTER | REDEEMER | GATEKEEPER |
|------|-------|--------|----------|------------|
| mint | — | ✅ | — | — |
| redeem | — | — | ✅ | — |
| transferToCustody | — | ✅ | — | — |
| disableMintRedeem | — | — | — | ✅ |
| reenableMintRedeem | ✅ | — | — | — |
| removeMinterRole | — | — | — | ✅ |
| removeRedeemerRole | — | — | — | ✅ |
| addSupportedAsset | ✅ | — | — | — |
| addCustodianAddress | ✅ | — | — | — |
| setMaxMintPerBlock | ✅ | — | — | — |
| grantRole | ✅ | — | — | — |
| revokeRole | ✅ | — | — | — |

### GATEKEEPER 安全约束

GATEKEEPER 的设计遵循 **"只能破坏，不能建设"** 原则：

```solidity
// 只能关停（设限额为 0），不能恢复
function disableMintRedeem() external onlyRole(GATEKEEPER_ROLE) {
    _setMaxMintPerBlock(0);
    _setMaxRedeemPerBlock(0);
}

// 只能移除角色，不能授予
function removeMinterRole(address minter) external onlyRole(GATEKEEPER_ROLE) {
    _revokeRole(MINTER_ROLE, minter);
}

function removeRedeemerRole(address redeemer) external onlyRole(GATEKEEPER_ROLE) {
    _revokeRole(REDEEMER_ROLE, redeemer);
}
```

### 多签与时间锁

```
DEFAULT_ADMIN_ROLE
    └── 7/10 多签（地理分布式）
        ├── 内部：4/10
        ├── 外部（安全公司、做市商）：3/10
        └── 时间锁：所有 ADMIN 操作需 7 天延迟
```

| 操作 | 时间锁 | 理由 |
|------|--------|------|
| grantRole/revokeRole | 7 天 | 权限变更需透明 |
| addSupportedAsset | 7 天 | 新资产需风险评估 |
| addCustodianAddress | 7 天 | 新托管商需尽职调查 |
| setMaxMintPerBlock | 7 天 | 供给参数变更 |
| setMaxRedeemPerBlock | 7 天 | 供给参数变更 |
| disableMintRedeem | 无 | GATEKEEPER 需应急响应 |
| removeMinterRole | 无 | GATEKEEPER 需应急响应 |

## 后果

### 正面
- GATEKEEPER 在 minter 私钥泄露时即时止损（per-block 限额确保最大损失可控）
- 多签地理分布防止单点故障
- 时间锁防止管理权限被滥用

### 负面
- 7 天时间锁降低了对紧急合约升级的响应速度
- 多签操作流程复杂，需要协调多个签名方

### 合约选择

使用 OpenZeppelin AccessControl，**不采用**原有的 SingleAdminAccessControl：

- OpenZeppelin AccessControl 是广泛审计的标准实现
- 支持多个 ADMIN 地址（多签场景）
