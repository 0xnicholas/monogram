# ADR-0008: 预言机与价格验证

## 状态

已采纳

## 背景

每笔 mint/redeem 前执行链上价格验证，确保订单价格与外部预言机的偏差在阈值内。阈值分资产设定（波动资产 500bps 为自定参数，非 Ethena 官方值；稳定币对齐 Ethena V2 `stablesDeltaLimit` 精神，收紧至几十 bps 级）。链下系统同时消费 Pyth、Redstone 和多 CEX 的数据馈送。

## 决策

### 链上价格验证

```solidity
interface IMonogramPriceFeed {
    function getPrice(address asset) external view returns (uint256 price, uint256 updatedAt);
    function getPriceAndTimestamp(address asset) external view returns (uint256, uint256);
}

// MonogramMinting 中的价格验证
uint256 public maxPriceDeviationBps = 500;  // 5%（波动资产默认值，分资产策略见下）

function _validatePrice(address asset, uint256 collateralAmount, uint256 mAmount) internal view {
    (uint256 price, uint256 timestamp) = priceFeed.getPrice(asset);

    // 检查时效（1 小时内）
    if (block.timestamp - timestamp > 3600) revert StalePrice();

    // 抵押品数量按其 decimals 归一化到 18 位（支持 USDC 等 6 位小数资产）
    uint8 assetDecimals = asset == NATIVE_TOKEN ? 18 : IERC20Metadata(asset).decimals();
    uint256 normalizedAmount = collateralAmount;
    if (assetDecimals < 18) {
        normalizedAmount = collateralAmount * (10 ** (18 - assetDecimals));
    } else if (assetDecimals > 18) {
        normalizedAmount = collateralAmount / (10 ** (assetDecimals - 18));
    }

    // 计算抵押资产美元价值
    uint256 collateralUsd = normalizedAmount * price / 1e18;

    // 计算偏差
    if (collateralUsd == 0 || mAmount == 0) revert InvalidAmount();

    uint256 deviation = _absDiff(collateralUsd, mAmount) * 10000 / mAmount;
    if (deviation > maxPriceDeviationBps) revert PriceDeviationExceeded();
}

function _absDiff(uint256 a, uint256 b) private pure returns (uint256) {
    return a > b ? a - b : b - a;
}
```

### PriceFeed 实现

```solidity
contract MonogramPriceFeed is IMonogramPriceFeed, AccessControl {
    bytes32 public constant ORACLE_ADMIN_ROLE = keccak256("ORACLE_ADMIN_ROLE");

    struct OracleConfig {
        address pythFeed;        // Pyth 合约地址
        address chainlinkFeed;   // Chainlink 合约地址
        uint128 maxAge;          // 最大时效
        uint128 maxDeviation;    // 双预言机最大偏差
        bool exists;
    }

    mapping(address => OracleConfig) public configs;

    function getPrice(address asset) external view override returns (uint256 price, uint256 updatedAt) {
        OracleConfig storage cfg = configs[asset];
        if (!cfg.exists) revert AssetNotConfigured();

        // 从 Pyth 获取（内部校验 price > 0 且 conf/price ≤ MAX_CONF_RATIO_BPS = 100bps）
        (uint256 pythPrice, uint256 pythTime) = _readPyth(cfg.pythFeed);

        // 从 Chainlink 获取
        (uint256 clPrice, uint256 clTime) = _readChainlink(cfg.chainlinkFeed);

        // 检查时效（两个预言机都必须未过期）
        if (block.timestamp - pythTime > cfg.maxAge) revert StalePythPrice();
        if (block.timestamp - clTime > cfg.maxAge) revert StaleChainlinkPrice();

        // 检查双预言机偏差
        uint256 deviation = _bpsDiff(pythPrice, clPrice);
        if (deviation > cfg.maxDeviation) revert OracleDeviationExceeded();

        // 取均值，并返回双源中较旧的时间戳（保守原则，供下游 StalePrice 检查）
        price = (pythPrice + clPrice) / 2;
        updatedAt = pythTime < clTime ? pythTime : clTime;
    }
}
```

### 分资产阈值策略（2026-08 更新，见 #6 resolution）

- **稳定币抵押品**（USDC/USDT 等）：对齐 Ethena V2 `stablesDeltaLimit` 精神，1:1 附近价差检查收紧至几十 bps 级，防脱钩套利（500bps 对稳定币太宽）。该机制（`stablesDeltaLimit` 复刻）属 Phase 1 正式实现范围，本 ADR 仅记录决策。
- **波动资产抵押品**（stETH/wstETH/ETH 等）：抵押品价值 vs M 数量偏差维持 500bps（自定参数，Ethena 官方未公布容差）。
- **双源交叉** `maxDeviation` 与 `maxAge`：作为独立参数按资产配置（见下表）。
- **Pyth 置信区间校验**：`conf / price > 100bps`（`MAX_CONF_RATIO_BPS`）时 revert `PriceConfidenceTooWide`；`price <= 0` 时 revert `InvalidPythPrice`。

### 链下价格验证

Pricing API 在报价前执行：

1. 聚合多 CEX 订单簿（Binance、Bybit、OKX）计算 VWAP
2. 与 Pyth 实时价格对比验证
3. 与 Redstone 价格对比验证
4. 计算滑点和执行成本
5. 返回含价格的 EIP-712 可签名 payload

## 后果

### 正面
- 双预言机冗余防单点故障
- Pyth 高频更新 + Chainlink 稳定基准互补
- 链上分资产阈值偏差保护防止价格操纵与脱钩套利

### 负面
- 预言机操纵仍可能（需同时攻破 Pyth + Chainlink）
- 链上价格验证增加每笔交易 Gas
- 新资产上线需预言机配置交易

### 不采用的设计
- ❌ 单一预言机 — 单点故障风险
- ❌ 链上 AMM TWAP — 操纵成本低，更新慢
