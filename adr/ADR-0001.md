# ADR-0001: 合成美元协议整体架构

## 状态

已采纳

## 背景

Monogram 是一个合成美元协议。采用 delta-neutral 策略——以 ETH/BTC 等加密资产为底层抵押，通过等量反向永续合约对冲价格风险，从资金费率、基差交易、DeFi 借贷和 RWA 中产生收益。

## 决策

### 合约层

| 合约 | 功能 |
|------|------|
| `M.sol` | 合成美元 ERC20，单 minter 模式 |
| `MonogramMinting.sol` | 铸造/赎回引擎，签名验证，价格校验，限额风控 |
| `StakedM.sol` | ERC-4626 Vault，自动复利收益 |

### 链下层

| 组件 | 功能 |
|------|------|
| Pricing API | RFQ 报价，滑点计算，订单验证 |
| Hedging Engine | delta-neutral 对冲，仓位管理，OES 协调 |
| Reserve Fund | 链下资金池，吸收负收益 |

### 关键设计原则

1. **Delta-neutral 合成美元** — 不需要超额抵押，依赖对冲保持价格稳定
2. **原子铸造/赎回** — `transfer asset → mint M` 和 `burn M → transfer asset` 单笔交易完成
3. **链下报价 + 链上执行** — RFQ 获取价格，EIP-712 签名确保订单不可篡改
4. **破产隔离托管** — 资产托管在 OES 提供商，不进入交易所钱包
5. **多源收益** — 资金费率、基差、DeFi 借贷、RWA 多样化

## 后果

### 正面
- 架构简洁，合约数量少（3 个核心合约），降低审计面
- 链上/链下责任清晰分离
- 合成美元设计在实践中被验证为可持续

### 负面
- 依赖链下系统运行，系统启动成本高
- 合成美元设计本质上依赖对冲操作的正确性

### 不采用的方案
- ❌ 超额抵押稳定币（如 DAI）— 资本效率低
- ❌ 法币抵押稳定币（如 USDC）— 需要银行关系
- ❌ 算法稳定币（如 UST）— 历史证明不稳定
- ❌ ContractRegistry — 注册表模式增加不必要的复杂度
- ❌ Route 比例路由 — 直接转账到 custodian 地址更简洁
